Palette

Amber is the signal colour: an active nav item, an eyebrow, a divider, a selected segment. Nothing large is amber. The chrome sits one shade darker than the content behind it, like dark water behind a lit surface.

Panels

One surface for a group of related things. A panel reads as a slightly raised area of the same surface, not as a second colour. .beacon-panel brings the padding; .beacon-panel--flush hands it to the rows instead, so their separators run edge to edge.

Dividers

One rule, everywhere: 1px solid var(--beacon-hairline), between siblings only, never after the last one. A second, quieter divider colour was tried in the track-info dialog and dropped - it only made that dialog the one place with two kinds of hairline.

Chips

For tags - a set the reader scans rather than reads. Not for a value that happens to be short: a bitrate or a year is one fact and stays plain text.

The artwork backdrop

The app's one hero effect: the artwork of whatever the surface is about, blurred past recognition behind it, under a scrim that keeps text readable and lands the amber on the far side. Album, artist, genre and playlist headers, Home's hero band, Now Playing and the track-info dialog all use this same recipe.

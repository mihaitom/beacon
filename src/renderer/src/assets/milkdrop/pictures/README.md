# Pictures for Beacon's own presets

Each file here reaches the shaders of a preset that mentions it as
`sampler_<file name>` (see `services/milkdrop/textures.ts`).

- `moon.jpg` - the Moon's near side, longitude -90 to 90 and latitude 90 to
  -90 left to right and top to bottom: the middle half of the colour map in
  NASA's CGI Moon Kit (Scientific Visualization Studio, svs.gsfc.nasa.gov
  item 4720, `lroc_color_poles_1k.jpg`), made from Lunar Reconnaissance
  Orbiter images. Public domain.
